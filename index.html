Why Ascendi

Lessons built around each student

Every lesson is planned for the student in front of me, and you always know how they're getting on.

  • Curated to each student

    Lessons are planned around your child's needs, pace and goals, never a one-size-fits-all worksheet.

  • A report every six weeks

    You get a written progress report every six weeks, so you can see what has improved and what comes next.

  • Understanding, not memory

    Students learn why a method works, so it still holds up when an exam question looks unfamiliar.

  • Parent support, 24/7

    Questions between lessons? Message any time. Parents get ongoing communication and support throughout.
